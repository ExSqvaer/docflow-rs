# DocFlow RS — учебный MVP

DocFlow RS — демонстрационный веб-прототип системы документационного обеспечения для ВКР. Он показывает регистрацию документов, согласование, резолюции, контроль сроков, отчеты, ролевой доступ, сессии, аудит и базовое администрирование.

## Быстрый запуск в Windows

1. Распакуйте архив.
2. Убедитесь, что установлен Python 3.11+.
3. Запустите `run_windows.bat`.
4. Браузер откроет `http://127.0.0.1:8000/login`.

При первом запуске создается виртуальное окружение и устанавливаются зависимости.

## Запуск вручную

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

## Ограничения MVP

Это локальный учебный прототип, а не промышленная СЭД. В нем нет интеграции с корпоративным каталогом/SSO, MFA, антивирусного шлюза, юридически значимого ЭДО и фоновой службы резервного копирования.

**Физическое файловое хранилище не подключено.** Вложения представлены метаданными тестового контура, поэтому кнопки скачивания намеренно отображаются неактивными с пояснением. Настройки почтовых уведомлений и резервного копирования сохраняются, но внешние сервисы не запускаются.

Для промышленной эксплуатации потребуются PostgreSQL, TLS, корпоративная идентификация, MFA, мониторинг, резервное копирование и полноценное файловое хранилище.
